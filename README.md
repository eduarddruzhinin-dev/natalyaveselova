# Лендинг: Наталья Веселова — кондитер-шоколатье

Статический сайт: файл index.html и папка images. Подходит для GitHub Pages.

## Как выложить на GitHub Pages
1. На github.com нажмите «+» -> New repository. Название, например, natalya-veselova. Для бесплатного аккаунта репозиторий должен быть Public.
2. На странице нового репозитория выберите «uploading an existing file».
3. Перетащите в окно всё содержимое этой папки: index.html, файл .nojekyll и папку images. Нажмите Commit changes.
4. Откройте Settings -> Pages. В разделе Build and deployment выберите Source: Deploy from a branch, Branch: main, папка / (root). Нажмите Save.
5. Через 1-2 минуты сайт откроется по адресу https://ВАШ-ЛОГИН.github.io/natalya-veselova/ (точный адрес GitHub покажет на этой же странице).

## Что важно знать
- Форма заявки работает так: клиент заполняет поля, получает готовый текст (он копируется) и отправляет его сообщением в сообщество ВКонтакте. GitHub Pages — статический хостинг, поэтому автоматическая отправка заявок в Telegram на нём недоступна.
- Чтобы поменять цену или текст, откройте index.html в репозитории (значок карандаша) и отредактируйте нужную строку.
- Чтобы заменить фото, загрузите в папку images новый файл с тем же именем.
